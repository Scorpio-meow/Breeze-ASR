01流程

從錄音到字幕，四個步驟

上傳、辨識、校對、匯出都在同一個網頁完成，服務跑在你自己的電腦上。

  1. 01

    上傳 m4a、mp3、wav、mp4 等常見格式，可以一次選多個排隊；也能拖進視窗、用瀏覽器錄音，或放進監看資料夾。

  2. 02

    Breeze ASR 25 辨識臺灣華語與中英夾雜，Breeze ASR 26 辨識臺灣台語、輸出華語漢字。可以加熱詞、自動標點、分辨說話者。

  3. 03

    在波形時間軸上直接改字、對時、分割合併、尋找取代；改錯了，按復原。

  4. 04

    匯出 SRT、VTT、ASS、TXT、Markdown、DOCX、JSON，或把字幕燒錄到原始影片。

05隱私

錄音與逐字稿留在這台電腦

開發者不經營任何伺服器，也不收集你的錄音、逐字稿與使用情形。沒有帳號、沒有分析追蹤、沒有廣告。

這台電腦

瀏覽器 Breeze ASR 服務 資料目錄結果、詞彙表、語者庫、日誌
監看資料夾
  • Hugging Face只在下載模型時
  • 手機、平板或其他電腦只有開放其他裝置連線時，要帶存取權杖
  • 既有的 Breeze ASR 服務只有設成 remote 的模型
  • AI 工具只有使用 MCP server 或 Agent Skill 時
  • 上傳的音訊辨識完就刪除辨識結果預設保留 1 天，從最後一次修改起算。
  • 用量回報都關閉OpenVINO、NNCF 與 Hugging Face 的用量統計不會送出。
  • 聲紋需要同意聲紋屬於個人生物特徵，記住別人的聲音前請先取得對方同意。

06命令列、MCP 與 Skill

批次轉檔，或讓 AI 助理直接呼叫

命令列工具、MCP server 與 Agent Skill 都呼叫這台電腦上執行中的服務，檔案不經過其他地方。

  • transcribe一次送出多個檔案，結果寫在原檔旁邊
  • jobs列出服務裡保留中的工作
  • export下載某個工作的任一格式
  • render把字幕燒進原始影片，下載 MP4
  • MCP 提供 7 個工具與「整理會議紀錄」「校對逐字稿」兩個提示
  • 裝上 Agent Skill，Claude Code、Codex 等 AI 工具會自己轉逐字稿、替說話者改名、整理會議紀錄

逐字稿會進到 AI 工具的對話裡，可能因此送到外部 AI 服務；不能交給外部 AI 的錄音，只用網頁或命令列工具。

07安裝

安裝與系統需求

安裝腳本會自動安裝 uv 與符合顯示卡的 PyTorch。啟動後開啟 http://127.0.0.1:7860，把音訊或影片拖進視窗，再按「辨識」。

  1. 取得程式碼
    git clone https://github.com/Scorpio-meow/Breeze-ASR.git
  2. 在專案根目錄開 PowerShell 執行
    powershell -ExecutionPolicy Bypass -File scripts\install.ps1

安裝完成後，桌面會有「Breeze ASR」捷徑。

  1. 取得程式碼
    git clone https://github.com/Scorpio-meow/Breeze-ASR.git
  2. 安裝
    bash scripts/install.sh
  3. 啟動
    bash scripts/start.sh
  1. 取得程式碼
    git clone https://github.com/Scorpio-meow/Breeze-ASR.git
  2. 建立設定檔
    cp .env.example .env
  3. 建置並啟動
    docker compose up -d --build

NVIDIA、AMD 顯示卡與 GitHub 發布的映像檔，見部署。

第一次啟動會下載約 9 GB 的模型並自動調校，約需數分鐘到十幾分鐘；之後啟動約 15 秒就緒。
